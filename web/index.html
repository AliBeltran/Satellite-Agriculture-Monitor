◇ ABOUT THIS PROJECT

Open agricultural intelligence.

Satellite Agriculture Monitor uses geospatial and satellite-observation technologies to help visualize and analyze agricultural fields.

It is designed to give producers, agronomists, conservation professionals, and anyone working in agriculture a practical way to explore field information and support better-informed decisions.

This project is open source and is being developed to make agricultural technology more accessible to producers and the agricultural community.
